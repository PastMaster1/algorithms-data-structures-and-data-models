## Спецификация реализованных структур данных

В проекте представлены реализации следующих структур данных:

1.  **StructureMinStack.cs:** Стек с поддержкой получения минимума за O(1).

---

## Условия задач

### StructureMinStack.cs:

Необходимо создать свой класс представляющий стек, который поддерживает операции добавления,
удаления, получения верхнего элемента и получения минимального элемента за константное время.

Должны быть реализованы следующие методы:
1. `void Push(int value)` - добавляет элемент value на вершину стека,
2. `void Pop()` - удаляет элемент, находящийся на вершине стека,
3. `int Top()` - возвращает верхний элемент стека,
4. `int GetMin()` - возвращает минимальный элемент стека,
5. `int Count()` - возвращает количество элементов в стеке.

Все методы должны работать за O(1) время.
Внутренне стек должен использовать односвязный список.

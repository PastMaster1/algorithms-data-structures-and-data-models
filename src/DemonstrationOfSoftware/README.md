# Algorithms And Data Structures Demo Of Software

Данный проект содержит интерактивное консольное приложение для демонстрации работы программ.

---

## Системные требования

Перед запуском убедитесь, что у вас установлены:
1.  .NET 8.0 SDK или выше.
2.  Утилита `make`.

---

## Инструкция по работе

* Сборка проекта: `make build`
* Запуск проекта: `make run`
* Собрать библиотеку со всеми зависимостями: `make publish`
* Собрать NuGet-пакет: `make pack`

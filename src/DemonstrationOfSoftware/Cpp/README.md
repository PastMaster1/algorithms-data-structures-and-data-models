# Algorithms, Data Structures and Data Models
## Demo Of Software On C++

Данная папка содержит интерактивное консольное приложение для демонстрации работы программ,
написанных на C++.

---

## Системные требования

Перед запуском убедитесь, что у вас установлена утилита `make` и компилятор `g++`.

---

## Инструкция по работе

* Сборка проекта: `make`
* Полностью пересобрать проект: `make rebuild`
